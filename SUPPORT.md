# Getting help

## First

1. Read [Troubleshooting](docs/troubleshooting.md). Most problems are a
   missing or outdated tool, and the fix is one command.
2. Check the [FAQ](docs/faq.md).
3. Search the existing issues in this repository.

## Opening an issue

Use the issue forms; they ask for what is needed to answer quickly:

- **Bug report** for something that does not work.
- **Feature request** for something you would like the app to do.
- **Documentation problem** for a mistake or gap in these pages.

For a bug, the most useful thing you can attach is the output for the row
that failed: click the page icon on that row, then **Copy**. Its first line
is the exact yt-dlp command the app ran.

Before you post, remove anything private from what you paste: links to
private or unlisted videos, your user name in file paths, and proxy
addresses.

## What cannot be helped with here

- Getting around a paywall, DRM, or a region or age restriction.
- A website that yt-dlp itself cannot download from. Try the same link with
  yt-dlp in Terminal; if it fails there too, the place to report it is the
  [yt-dlp project](https://github.com/yt-dlp/yt-dlp).

Security problems are reported privately; see [SECURITY.md](SECURITY.md).
