# Contributing

Thank you for helping to make these documents better.

## What you can contribute here

This repository contains documentation only. The app's source code is not
public, so code changes cannot be proposed here. You can:

- **fix or improve the documentation** with a pull request;
- **report a bug** in the app, or **suggest a feature**, with an issue;
- **report a mistake or gap** in the documentation with an issue.

## Documentation changes

1. For anything larger than a typo, open an issue first and say what you
   want to change, so nobody does the work twice.
2. Fork the repository and make the change on a branch.
3. Keep to the conventions below.
4. Open a pull request and fill in the template.

### Conventions

- Write for someone who uses the app but does not program. Spell out the
  steps; do not assume Terminal experience without giving the command.
- Describe what the app does today. Do not document plans.
- Use the names exactly as the app shows them, in bold: **Add to Queue**,
  **Whole playlist**.
- Write menu paths as: Settings > Network.
- Put commands in fenced code blocks with the language `sh`.
- One topic per page. New pages start from
  [docs/templates/doc-page.md](docs/templates/doc-page.md) and are added to
  the table in the README.
- Do not add instructions for getting around paywalls, DRM, or region or age
  restrictions.
- Screenshots: PNG, in `assets/`, taken in light mode, with nothing personal
  visible (no private video titles, no user name in paths).

## Reporting bugs and suggesting features

Use the issue forms. See [SUPPORT.md](SUPPORT.md) for what to include.
